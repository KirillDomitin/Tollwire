# Карта серверов WirePilot

Базовый коммит `c0ebd69a628a7b14614af81aead2fff788f22dc0`. Цель — показать расположение и состояние серверов на странице «Серверы» по согласованному эскизу.

## Согласованное решение

Отдельная nullable-колонка `vpn_servers.location_city_id`. Существующие методы создания, чтения и обновления используют одноимённое поле. Пропуск в PATCH сохраняет значение, `null` его очищает. Миграция оставляет город пустым у существующих серверов. Координаты, названия и геометрия поставляются с фронтендом. Флаг остаётся частью имени сервера.

Карта использует тёмную палитру и шрифт WirePilot. Заголовок и счётчик видны при свёрнутой карте, управление масштабом расположено справа над картой, а список выбранных серверов — под ней. Поиск и фильтры подают на карту и в таблицу один набор серверов. Фиксированный размер меток в экранных пикселях сохраняет читаемость при приближении, а расстояние между ними определяет состав группы.
