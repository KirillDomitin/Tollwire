Правка: $ARGUMENTS

Без агентов, без плана в `docs/plans/`. Экономь контекст.

1. **Найти.** Grep или `smart_outline` / `smart_unfold` (claude-mem), чтобы увидеть нужную функцию. Целые файлы
   не читай. `CLAUDE.md` модуля — только если правка затрагивает его инварианты.
2. **Поправить** минимально, в стиле соседнего кода. Если задача оказалась шире (несколько слоёв, модель БД,
   `VPNProvider`, контракт фронтенда) — остановись и предложи `/feature`.
3. **Проверить.** `uv run pytest --testmon -q -x` (фронтенд — `npm test -- <файл>`), `uv run ruff check .`,
   `uv run mypy src`. Полный прогон не запускай.
4. **Баг — тест.** Если это исправление бага и подходящего теста нет, добавь один маленький.
5. **Итог** — 2–3 строки: что изменено и что проверено. Коммит — только если попросили.
