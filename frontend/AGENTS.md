# Веб-интерфейс

Перед работой читать [CLAUDE.md](CLAUDE.md), [структуру](../docs/frontend/structure.md),
[контракт Bot API](../docs/bot/api.md) и [уведомления](../docs/bot/notify.md).

- Видимость вкладок и действий определяют permissions; собственные уведомления — `bot:notify`.
- Одноразовый код привязки не сохранять в кеше; мутация `gcTime: 0`, запрос выпуска `no-store`.
- Ссылки/коды приглашений — тоже только в мутации `gcTime: 0`; очищать при закрытии, не повторять выпуск
  автоматически и не закрывать окно до ответа. Выбор получателей сохранять между страницами и поиском.
- После PUT событий обновлять кеш значениями ответа; частичное обновление не теряет остальные события.
- Настройки показывают минуты, API хранит целые секунды: сохранять точный порог (включая 90 с).
- Неизменённые поля формы берут свежие настройки сервера; пользовательский черновик сохраняется до успешной записи.
- Не редактировать сгенерированные типы вручную: OpenAPI → `npm run gen:api`; переводы обновлять в ru/en.
- Образы протоколов — [контракт](../docs/servers/protocol-updates.md). Статус относится к конкретному protocol_id,
  а не серверу целиком; cached GET не запускает проверку. Чтение — servers:read, «Проверить обновления» —
  servers:check, замена с подтверждением — servers:manage. Устаревшие сведения не показывать как свежие;
  после завершения задачи инвалидировать кеш. APP-контейнеры не предлагать обновлять.
