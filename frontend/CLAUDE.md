# frontend — WirePilot

React 19, Vite, TypeScript strict, React Router, TanStack Query, openapi-fetch, Radix; Node 24.
Проверки: typecheck/lint и затронутые тесты; полный прогон/build по корневым правилам.
Справочники читать только по теме: [структура](../docs/frontend/structure.md),
[подробный справочник](../docs/frontend/agent-reference.md) (карта файлов, тесты, сборка).
Публичная /c вне AuthProvider; токен только в теле POST, no-store, очистка на pagehide.
WithAuth сохраняет сессию при смене языка.

## Дизайн WirePilot

- Продукт называется **WirePilot** (логотип — щит с буквой W, `BrandMark`; `<title>`, favicon, словари ru/en). Имена `vpn-panel`,
  образы, compose-проект и URL репозитория — технические, их не менять.
- Тема **одна — тёмная** (тёмно-синий фон, поверхности-карточки, тонкие синие границы, акцент `--accent` #1a73ff). Светлой темы,
  переключателя и `prefers-color-scheme` нет — не возвращать. Цвета только через токены.
- Статус всегда дублируется текстом (`StatusPill`: точка + подпись); зелёный/жёлтый/красный — `--signal-ok/warn/down`.
- **Сайдбар закреплён**: `position: sticky; height: 100dvh`, прокручивается только контент справа. Ниже 768px — верхняя панель с
  кнопкой «Меню». Проверять на длинных страницах (карточка сервера, журнал) и на 375px без горизонтального переполнения.
- Только визуальный редизайн: данных, которых нет в API (тарифы, имя/телефон, уровни логов INFO/WARN/ERROR, ёмкость сервера),
  не рисуем и не выдумываем — берём аналоги из реальных данных.
- Таблицы — только через `DataTable.module.css` (`wrap`, `table`, `stack` + `data-label` на узком экране); состояния — `StatusPill` или пилюля в стиле `StatusPill` (`.badge` в `Gateway.module.css`, `ImportClientsDialog.module.css`).
- Lighthouse «Доступность» = 100 — держать. Мобильная ширина без горизонтальной прокрутки.

## Правила

- Новый видимый текст — только через `t(...)`, ключ в **обоих** словарях (`i18n.test.ts` следит за совпадением ключей
  и `{{подстановок}}`). Склонения — плюральными ключами (`key_one/_few/_many/_other` в ru, `_one/_other` в en), не
  `if (n === 1)`. Даты, числа, единицы — через `Intl` с `currentLanguage()`, а не с жёстким `"ru"`.
- Тесты идут на русском: `src/test/setup.ts` перед каждым тестом включает ru. Проверка другого языка — `i18n.changeLanguage("en")`.
- Кнопки и разделы показывать по правам (`can(...)`), viewer — только чтение.
- Исключение — свои уведомления (`bot:notify`): viewer может привязать/отвязать свой Telegram, выбрать события и
  отправить проверку. Код привязки — только в мутации с `gcTime: 0`, сброс при закрытии; после успешной привязки
  компонент с кодом размонтируется. Опрос привязки прекращается при закрытии, истечении кода или `linked` без
  `blocked_at`; старая заблокированная привязка не должна закрывать окно нового кода.
- Новое событие аудита — строка в `AUDIT_ACTIONS` (группа, тон) **и** `audit.actions.<action>` в обоих словарях (оба — `Record`/типизированные ключи по openapi: без них typecheck падает).
  В подробности выводятся только ключи из белого списка `DETAIL_LABELS` и `changes`.
- Опрос задач: каждые 2 с, пока есть pending/running; по завершении — invalidate связанных запросов.
- Конфиг: `useMutation` с `gcTime: 0`, сброс при закрытии диалога; QR и конфиги не скриншотить (в них ключ).
- uPlot рисует на canvas: цвета читать из CSS-переменных (`--chart-*`) через `getComputedStyle`; тона линий — `blue/green/violet`
  и пунктир `peak`; заливка под линией — градиент, но не до первой отрисовки (у легенды ещё нет области — тогда сплошной цвет);
  пропсы-массивы — константы или `useMemo` (иначе график пересоздаётся на каждой отрисовке).
- В отрисовке не вызывать `Date.now()` (правило чистоты React) — брать `dataUpdatedAt` из запроса.
- `qrcode` без `@types/qrcode` (npm ломает установку) — свои типы `src/types/qrcode.d.ts`.

  `vi.mock("uplot")`.
